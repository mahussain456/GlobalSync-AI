# Free-tool reliability and search rendering release

This release repairs empty recent-query history, misleading freelance calculator claims, invalid negative rates, incomplete initial HTML and analytics event formatting.

## Resulting behavior

- Builds render the real application for all 359 configured routes. Browser launch or rendering errors fail the build instead of generating title-only fallback pages. Chromium 143 and Puppeteer 24.35.0 support the Vercel build environment.
- The freelance tool converts rates across its 11 supported currencies and estimates gross annual revenue using explicit hours/weeks/project assumptions. Valid settings persist on the current browser.
- The last 30 natural-language queries are remembered on the current browser, can be replayed, and expire on a subsequent read after 90 days. The former global history API returns 410; public lead listing returns 403.
- Team links remain public and readable. New workspaces are stored in the browser and encoded into complete share links, so creation and sharing work without a configured database. The legacy server creation route uses random identifiers and immutable inserts. Email-only enumeration, client-claimed paid workspaces and caller-selected replacement slugs are rejected. Public responses exclude owner contact and consent fields. Legacy server creation requires durable database storage and has a per-process request-rate limit; no email is collected or sent by new team creation. Existing data is not deleted. Private authenticated sync is not implemented or advertised.
- Invoice quantity labels follow hourly, monthly or project billing in the form, preview and generated PDF.
- Tool events use the Google tag API only after consent. Homepage result/export events, accessible city-removal names and an AI request timeout improve measurement and usability.
- Sitemap lastmod is omitted when an actual content-change date is unavailable. Team pages receive noindex and private/no-store headers; APIs are not publicly cached. Unknown URLs retain the 404 behavior.

## Validation

- 30 JavaScript tests in seven suites pass.
- Seven Python tests (including the actual ASGI entry point) exercise disabled endpoints, team creation boundaries, public projection, input validation and storage outage handling, without using production records.
- Browser checks confirm saved-query replay, retained calculator settings and monthly/project invoice labels and totals.
- Full application prerender and built-page checks are required before release. Vercel preview status is checked before pushing the same release to main. Production verification checks actual content and endpoint responses, not only deployment status.

## Remaining limits

Production has no database or email sender configuration. Browser workspaces and complete share links work without those services; legacy server workspace storage and email delivery remain unavailable until configured. Real calendar import and paid billing are not certified by this release. Some existing paid-feature prompts remain outside the revised team flow; purchases remain unavailable. Dependency audit reports require a separate exploitability/remediation review. No traffic, ranking or revenue outcome is promised.
